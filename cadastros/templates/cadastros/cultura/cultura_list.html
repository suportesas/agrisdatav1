Como Cadastrar e Gerenciar Culturas?
O que é uma Cultura?
Uma cultura é qualquer produto agrícola que você cultiva ou produz em sua fazenda. Exemplos: melão, melancia, milho, abóbora, tomate, cebola, etc. As culturas são vinculadas aos plantios para rastreamento de produção e gerenciamento de operações agrícolas.
Passo a Passo

  • Clique no botão Nova Cultura
  • Preencha os campos obrigatórios:
    • Nome da Cultura: Nome científico ou comum (ex: "Melão Amarelo", "Milho Safrinha")
    • Tipo/Categoria: Classifique conforme seu negócio:
      • 🥬 Hortaliça - Alface, repolho, brócolis, etc
      • 🍅 Fruta - Melão, melancia, morango, etc
      • 🌽 Grão - Milho, soja, feijão, etc
      • 🥔 Raiz/Tubérculo - Batata, mandioca, beterraba, etc
      • 🌾 Forrageira - Silagem, pasto, capim, etc
      • Outro - Outros tipos
    • Ciclo (dias): Dias necessários desde plantio até colheita
    • Temperatura Ideal (°C): Intervalo recomendado (ex: "20-30")
  • Clique em Salvar
Dica: Seja específico no nome para diferenciar variedades (ex: "Melão Galia" vs "Melão Cantaloupe")!

  • Descrição: (Opcional) Detalhes sobre a cultura, características, usos, etc
  • Código da Cultura: (Opcional) Código interno para referência rápida
  • Umidade Ideal (%): (Opcional) Percentual recomendado (ex: "60-80%")
  • pH do Solo Ideal: (Opcional) Nível recomendado (ex: "6.0-7.0")
  • Espaçamento (m): (Opcional) Entre plantas e linhas (ex: "0.20 x 0.40")
  • Produção Esperada: (Opcional) Produtividade estimada por unidade
  • Unidade de Medida: (Opcional) Padrão para colheita (kg, caixas, sacos, etc)
  • Ativo: Marque para deixar a cultura disponível para plantios
Quanto mais informações detalhadas, melhor o rastreamento e planejamento de operações!

  • Na tabela de culturas, localize a cultura desejada
  • Clique na cultura para ver detalhes ou no ícone de edição
  • Modifique as informações necessárias:
    • Nome e categoria
    • Ciclo e condições ideais
    • Status (ativo/inativo)
    • Outras informações agronômicas
  • Clique em Salvar para atualizar
Atenção: Se desativar uma cultura, ela não aparecerá em novos plantios, mas os plantios anteriores continuam histórico!

  • Use a barra de busca para procurar por:
    • Nome da cultura
    • Código interno
    • Tipo/categoria
  • Filtre por:
    • Tipo: Hortaliça, Fruta, Grão, etc
    • Status: Ativas ou Inativas
  • Use paginação para navegar por listas grandes

  • Limite do Plano: Seu plano permite um número máximo de culturas
  • Verificar Limite: Veja nos cards de estatística quantas culturas você já tem cadastradas
  • Vagas Disponíveis: O sistema mostra quantas culturas ainda podem ser criadas
  • Se o limite for atingido: Será necessário atualizar seu plano ou desativar culturas não utilizadas
  • Plano Ilimitado: Alguns planos permitem culturas ilimitadas (mostrado com ∞)
Desative culturas não utilizadas em vez de excluir, para manter histórico de plantios anteriores!
Informações Importantes
  • Vinculação: As culturas são vinculadas aos plantios para rastreamento
  • Exclusão: Uma cultura com plantios associados não pode ser deletada
  • Desativação: Prefira desativar em vez de excluir para preservar histórico
  • Informações Agronômicas: Ajudam no planejamento e em cálculos de produtividade
  • Variedades: Crie entradas separadas para variedades diferentes (não combine em uma)
Boas Práticas
  • Mantenha nomes claros e específicos para cada variedade
  • Registre sempre os dados agronômicos (ciclo, temperatura, pH, etc)
  • Agrupe culturas similares por tipo/categoria para melhor organização
  • Atualize informações conforme aprende mais sobre as culturas
  • Use código interno para referências rápidas no campo
  • Mantenha um histórico completo mesmo de culturas descontinuadas
  • Documente requisitos especiais na descrição (ex: irrigação, pesticidas, etc)
  • Sincronize com fornecedores de sementes para manter dados atualizados

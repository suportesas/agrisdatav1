Ir para Conferência
Onde imprimir etiquetas?
  • Etiqueta simples (sem dados do cliente): Abra a Ordem de Embalagem → clique em Etiquetas PDF. Gera uma etiqueta por pallet com código de barras, rastreamento, pesos e lote.
  • Etiqueta com dados do cliente/exportação: Abra o Romaneio de Venda (confirmado) → clique em Etiquetas PDF. Inclui cliente, cidade, país, armador, navio, container (para exportação).

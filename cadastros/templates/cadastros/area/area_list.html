Como Cadastrar e Gerenciar Áreas?
O que é uma Área?
Uma área é uma porção de terra dentro de uma fazenda, caracterizada por sua localização, tamanho e tipo de uso (agrícola, pastagem, reserva, etc). As áreas podem ser subdivididas em talhões para melhor gerenciamento.
Passo a Passo

  • Clique no botão Nova Área
  • Preencha os campos obrigatórios:
    • Nome: Identificação da área (ex: "Talhão Sul", "Pasto A")
    • Fazenda: Selecione a fazenda à qual a área pertence
    • Tipo: Escolha o tipo de uso:
      • 🌾 Agrícola - Área para plantio de culturas
      • 🐄 Pastagem - Área para criação de gado
      • 🌳 Reserva - Área de reserva ambiental
      • 🛡️ APP - Área de Proteção Permanente
      • Infraestrutura - Estradas, galpões, etc.
    • Área Total: Tamanho em hectares (ha)
  • Clique em Salvar
Dica: Use nomes claros e descritivos para facilitar a identificação no campo!

  • Código Interno: (Opcional) Código personalizado para referência interna
  • Área de Reserva: Quantidade de hectares reservados (não utilizáveis)
  • Status da Área: Define a situação atual:
    • ✓ Disponível - Pronta para uso
    • ⚡ Em Uso - Ocupada com cultivo/criação
    • ⏸ Descanso - Em período de pousio
    • 🔧 Preparação - Sendo preparada para plantio
    • ✗ Inativa - Temporariamente indisponível
  • Localização/Coordenadas: (Opcional) Informações de geolocalização
O sistema calcula automaticamente a área disponível (Total - Reserva) e o percentual de uso!

  • Na tabela de áreas, localize a área desejada
  • Clique no ícone para ver opções:
    • Visualizar: Ver detalhes completos da área
    • Editar: Modificar informações da área
    • Excluir: Remover a área do sistema
  • Os dados são atualizados em tempo real
Atenção: Só é possível excluir uma área se ela não tiver talhões associados!

  • Use a barra de busca para procurar por:
    • Nome da área
    • Código interno
    • Nome da fazenda
  • Filtre por:
    • Fazenda: Exibir áreas de uma fazenda específica
    • Tipo: Agrícola, Pastagem, Reserva, APP, etc.
    • Status: Disponível, Em Uso, Descanso, etc.
  • Clique em no cabeçalho para exibir os campos de busca, depois em Filtrar para aplicar
Informações Importantes
  • Área Total: Tamanho total em hectares (não pode ser alterado após criação)
  • Área Disponível: Calculada automaticamente como (Total - Reserva)
  • Percentual de Uso: Indica quanto da área está sendo utilizada
  • Talhões: Subdivisões da área para melhor gerenciamento
Boas Práticas
  • Mantenha os nomes das áreas consistentes e descritivos
  • Atualize o status conforme as mudanças de uso
  • Registre a área de reserva para cálculos precisos
  • Subdivida áreas grandes em talhões para melhor controle
  • Realize auditorias periódicas dos dados cadastrados
  • Use a localização/coordenadas para rastreamento via GPS

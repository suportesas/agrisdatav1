Como Fazer Inventário Cíclico?
O que é?
O Inventário Cíclico é uma contagem periódica e parcial do estoque, focando nos itens mais importantes (classificação ABC) sem interromper as operações.
Passo a Passo

  • Clique no botão + Novo Inventário
  • Selecione o Armazém que será inventariado
  • Escolha a Classificação ABC:
    • A - 80% do valor (itens mais importantes) ⭐
    • B - 15% do valor (itens intermediários)
    • C - 5% do valor (itens menos críticos)
    • Todos - Inventário completo
  • Clique em Criar Inventário
Dica: Comece sempre pela Classe A (produtos mais valiosos)!

  • Na lista, clique no ícone para Visualizar o inventário
  • Você verá todos os itens com suas quantidades do sistema
  • Para cada item:
    1. Clique no botão
    2. Vá até o local físico e conte o produto
    3. Digite a quantidade contada
    4. Se houver divergência, informe o motivo
    5. Clique em Salvar Contagem
O sistema calculará automaticamente a diferença e destacará divergências!

  • Após contar todos os itens, clique em
  • O sistema irá:
    • Verificar se todos os itens foram contados ✓
    • Criar ajustes automáticos para divergências
    • Calcular a acurácia do inventário
    • Atualizar o status para CONCILIADO
Atenção: Só concilie após contar todos os itens! A operação não pode ser desfeita.

  • Após conciliar, revise os dados
  • Verifique a acurácia percentual:
    • ≥ 95% - Excelente ⭐⭐⭐
    • ≥ 90% - Bom ⭐⭐
    • < 90% - Precisa melhorar ⚠️
  • Clique em
  • Status mudará para FINALIZADO
Análise de Resultados

Boas Práticas
  • Realize inventários regularmente (ex: mensalmente para classe A)
  • Conte em horários de baixo movimento
  • Use equipes de 2 pessoas (um conta, outro anota)
  • Documente todos os motivos de divergência
  • Mantenha a meta de acurácia ≥ 95%

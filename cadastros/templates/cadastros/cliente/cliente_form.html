Guia de Cadastro de Cliente

Este formulário registra todos os dados de um cliente no sistema. Abaixo você encontra a explicação de cada seção, campo e as tabelas do banco de dados envolvidas.

CampoObrigatórioDescrição
Razão Social / NomeSimNome completo ou razão social do cliente. Para pessoa física, use o nome completo.
Nome ComercialNãoNome fantasia ou nome de uso comercial (diferente da razão social).
CNPJ/CPFSimDocumento fiscal principal. O botão Buscar consulta a Receita Federal via API ReceitaWS e preenche automaticamente endereço, razão social e dados de contato.
Tipo ClienteNãoNacional: cliente dentro do Brasil. Importador: cliente no exterior — habilita campos de exportação.
Tipo PessoaNãoPJ: Pessoa Jurídica (CNPJ). PF: Pessoa Física (CPF). Afeta o Indicador IE e validações fiscais.
Contato PrincipalNãoNome, telefone e e-mail do contato principal do cliente. Pode ser complementado com contatos adicionais após o cadastro inicial.

CampoDescrição
Inscrição Estadual (IE)Número do registro estadual para contribuintes de ICMS. Obrigatório para emissão de NF-e em algumas operações.
Inscrição Municipal (IM)Número do cadastro municipal — necessário para serviços e NFS-e.
Inscrição SUFRAMAObrigatório para clientes na Zona Franca de Manaus — garante benefícios fiscais da SUFRAMA.
EORIEconomic Operators Registration and Identification — número de registro aduaneiro da União Europeia para exportações.
Regime TributárioRegime fiscal do cliente: Simples Nacional, Lucro Presumido, Lucro Real etc. Impacta o cálculo de impostos nas vendas.
VAT / Número RegistroIdentificação fiscal para clientes no exterior (IVA europeu, Tax ID americano, etc.).
Contribuinte ICMSMarque se o cliente é contribuinte do ICMS. Afeta o campo Indicador IE automaticamente.
Indicador IEPreenchido automaticamente com base em Tipo Pessoa e Contribuinte ICMS. Valores: 1=Contribuinte ICMS, 2=PJ isenta de IE, 9=Não contribuinte (PF).

Campos relevantes principalmente para clientes do tipo Importador (exterior).

CampoDescrição
PaísPaís de localização do cliente. Padrão: Brasil.
Moeda PadrãoMoeda utilizada nas negociações com este cliente (ex: USD, EUR). Requer cadastro prévio em Moedas — ou crie direto aqui pelo botão Adicionar.
Porto DestinoPorto de destino padrão para embarques. Vinculado ao cadastro de Portos do sistema.

CampoDescrição
Limite de CréditoValor máximo de crédito concedido ao cliente. Utilizado para controle de risco nas vendas.
Forma de Pagamento PadrãoMétodo de pagamento preferencial (Boleto, PIX, Transferência, Cartão etc.). Pode ser sobrescrito em cada pedido.
Desconto Padrão (%)Percentual de desconto concedido automaticamente nos pedidos deste cliente.
Vendedor ResponsávelVendedor da empresa responsável pelo atendimento deste cliente. Vinculado ao cadastro de Vendedores.
Preset PrazoDefine o prazo de pagamento padrão a partir de um conjunto de presets da empresa (ex: 30/60/90 dias). Crie novos presets clicando no botão +.
Observações ComerciaisCampo livre para anotações internas sobre negociações, condições especiais ou histórico comercial.
Acesso ao PortalHabilita o acesso do cliente ao Portal do Produtor/Cliente. O campo Usuário Vinculado é preenchido automaticamente com o usuário logado.

O registro de cliente se relaciona com as seguintes tabelas. As tabelas marcadas com CASCADE são excluídas junto com o cliente; as com SET NULL apenas perdem a referência.

TabelaRelaçãoComportamentoDescrição
cadastros_cliente—PrincipalTabela principal com todos os dados do cliente.
empresas_empresaForeignKey → EmpresaCASCADEEmpresa proprietária do cliente (multi-tenant).
cadastros_endereçocliente← EnderecoClienteCASCADEEndereços do cliente: Principal, Faturamento, Cobrança, Entrega, Notify.
cadastros_contatocliente← ContatoClienteCASCADEContatos adicionais: Principal, Financeiro, Operacional, Técnico, Emergência.
cadastros_contabancáriacliente← ContaBancariaClienteCASCADEContas bancárias e chaves PIX, SWIFT e IBAN do cliente.
cadastros_documentocliente← DocumentoClienteCASCADEDocumentos anexados: contratos, certidões, licenças etc.
cadastros_vendedorForeignKey → VendedorSET NULLVendedor responsável pela conta do cliente.
cadastros_prazopagamentopadraoForeignKey → PrazoPagamentoPadraoSET NULLPreset de prazo de pagamento (ex: 30/60/90 dias).
cadastros_portoForeignKey → PortoSET NULLPorto de destino padrão para operações de exportação.
usuarios_usuarioForeignKey → UsuarioSET NULLUsuário vinculado ao portal do cliente e usuário que realizou o cadastro.
Dados adicionados após o cadastro: Endereços, contatos adicionais, contas bancárias e documentos são gerenciados na página de detalhes do cliente, após salvar o cadastro inicial.

  1. Informe o CNPJ/CPF e clique em Buscar para preenchimento automático via Receita Federal.
  2. Confirme ou ajuste Razão Social, Tipo Cliente e Tipo Pessoa.
  3. Preencha os dados fiscais relevantes (IE, regime tributário, SUFRAMA se for Zona Franca).
  4. Para clientes no exterior: preencha País, Moeda Padrão e Porto Destino.
  5. Defina as condições comerciais: Limite de Crédito, Forma de Pagamento, Desconto e Vendedor Responsável.
  6. Selecione o Preset de Prazo de pagamento (crie novos presets pelo botão + se necessário).
  7. Clique em Salvar Cliente.
  8. Na página de detalhes, adicione endereços adicionais, contatos, contas bancárias e documentos.

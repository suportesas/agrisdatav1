# Governanca da Documentacao

Owner: Engenharia
Status: Draft
Last Updated: 2026-07-01
Scope: Processo editorial

## Politica
- Documentacao vive no mesmo ciclo do codigo.
- Mudanca de regra sem update de doc nao deve ser aprovada.
- Sempre preencher metadados obrigatorios.

## Fluxo de revisao
1. Autor cria/atualiza documento.
2. Revisor tecnico valida precisao.
3. Revisor de negocio valida clareza funcional.
4. Merge com registro no CHANGELOG_DOCS.md.

## Definicao de pronto para documento
- Objetivo claro
- Regras completas
- Exemplo reproduzivel
- Referencia de codigo
- Referencia de testes
- Data e owner atualizados

## Padrao de status
- Draft: em elaboracao
- In Review: aguardando revisao
- Approved: pronto para uso
- Deprecated: mantido apenas para historico

1. Arquitetura de Usuários e Grupos

Como o sistema organiza usuários, empresas e grupos corporativos:

🏛️ GRUPO CORPORATIVO

Holding/Matriz - Enterprise Plus

Exemplo: TerraCoop

Administrador: admin_terracoorp

Permissão: Ver dados consolidados de todas as empresas

Contém múltiplas empresas

🏢 EMPRESA 1

Nome: Agricola Salutaris S.A

Grupo: TerraCoop

👥 Usuários:

admin_agricola (ADMIN) gerente_campo (GERENTE) func_estoque (FUNCIONÁRIO)
🏢 EMPRESA 2

Nome: Potiguar Fruit

Grupo: TerraCoop

👥 Usuários:

admin_potiguar (ADMIN) vendedor_fruta (VENDEDOR) fin_finance (FINANCEIRO)

Isolamento Multi-tenant: Usuários de Empresa 1 só veem dados da Empresa 1. Não conseguem acessar Empresa 2 mesmo que tentem.

Resumo da Hierarquia
Nível Exemplos Quantidade Acesso
🏛️ Grupo Corporativo TerraCoop, GrupoAgro, etc 1 por grupo Consolidado de todas as empresas
🏢 Empresa Agricola Salutaris, Potiguar Fruit N empresas por grupo Dados isolados da empresa
👤 Usuário admin_agricola, gerente_campo N usuários por empresa Conforme tipo (ADMIN, GERENTE, etc)
Modelos Django
  • GrupoCorporativo - Holding/Matriz
  • Empresa - Filial vinculada
  • Usuario - Cada usuário
Relacionamentos
  • 1 Grupo → N Empresas
  • 1 Empresa → N Usuários
  • 1 Usuário → 1 Empresa
2. Como Criar Usuários
Cenário 1 Admin de Empresa Criando Usuários
1
Acesso ao Menu

Faça login como Admin da Empresa → Menu Lateral → Usuários

2
Novo Usuário

Clique em "Adicionar Novo Usuário" ou "+"

3
Preencher Formulário

Campos a preencher:

Username: gerente_campo
Email: gerente@empresa.com.br
Senha: SenhaForte123!@#
Nome Completo: João Silva
Tipo: GERENTE, VENDEDOR, FINANCEIRO, etc
Empresa: 🔒 BLOQUEADO = Sua Empresa
✅
Salvar

Clique em "Salvar" → Usuário criado com sucesso!

Importante: O campo "Empresa" está BLOQUEADO. Você só pode criar usuários para sua empresa.
Cenário 2 Superusuário Criando Usuários
1
Acesso ao Admin

Acesse: /admin/ com sua conta superusuário

2
Seção Usuarios

Clique em "Usuarios" → "Add Usuario"

3
Preencher Formulário (COM PRIVILÉGIOS)

Diferença: Campo "Empresa" está ABERTO

Username: admin_potiguar
Email: admin@potiguar.com.br
Tipo: ADMIN
Empresa: 🟢 ABERTO = Escolha qualquer empresa
✅
Configurar Permissões

✅ Staff status (acesso ao admin)
❌ Superuser status (deixe desmarcado)

Privilégio Superusuário: Você pode escolher para qual empresa criar o usuário, diferente dos admins de empresa.
3. Permissões e Tipos de Usuário

Cada tipo de usuário tem permissões diferentes:

Permissão Superuser Admin Gerente Funcionário
Ver dashboard própria empresa ✅ ✅ ✅ ✅
Ver relatório consolidado (grupo) ✅ ✅ ❌ ❌
Criar usuário em sua empresa ✅ ✅ ❌ ❌
Criar usuário em outra empresa ✅ ❌ ❌ ❌
Acessar admin do Django (/admin/) ✅ ✅ ❌ ❌
Ver dados de outras empresas Relatórios ❌ ❌ ❌
Superusuário

Uso: Administrador do sistema inteiro

Acesso: Todas as empresas

Exemplo: Seu admin principal da plataforma

Administrador

Uso: Admin de uma empresa específica

Acesso: Apenas sua empresa

Exemplo: admin_agricola, admin_potiguar

Gerente

Uso: Gerencia operações da empresa

Acesso: Módulos específicos (vendas, estoque)

Exemplo: gerente_vendas, gerente_estoque

Funcionário

Uso: Acesso limitado a tarefas específicas

Acesso: Apenas função atribuída

Exemplo: operacional, técnico

Dica: Use o tipo de usuário mais restritivo possível. Assim você garante a segurança da sua plataforma.
4. Perguntas Frequentes

Ele NÃO consegue! O sistema está isolado por empresa (isolamento multi-tenant).

Se um usuário pertence à Empresa 1:

  • ✅ Vê dados da Empresa 1
  • ❌ Não vê dados de Empresa 2, 3, etc
  • ❌ Nem consegue fazer login se tentar mudar a empresa

Apenas Admins do Grupo conseguem acessar:

  • Vendas totais de todas as empresas
  • Estoque consolidado
  • Faturamento por empresa
  • Comparativos de desempenho

Como acessar: Menu Lateral → Grupos Corporativos → Selecione o Grupo → "Relatório Consolidado"

SIM! Um Admin pode criar outros Admins para sua empresa.

Passos:

  1. Faça login como Admin
  2. Menu → Usuários → Novo Usuário
  3. Tipo: selecione "ADMIN"
  4. Empresa: será sua empresa automaticamente
  5. Salve

SIM, você pode deletar, mas com cuidado:

O que acontece:

  • O usuário é marcado como "inativo" (geralmente não deletado)
  • Dados dele não são perdidos
  • Registros continuam associados a ele
  • Ele não consegue mais fazer login

Alternativa: Em vez de deletar, desative o usuário. Vá em Usuários → Editar → Desmarque "Ativo"

Opção 1 - Como Admin:

  • Vá em Usuários
  • Clique no usuário
  • Clique em "Alterar Senha"
  • Digite uma nova senha
  • O usuário pode mudar depois no primeiro login

Opção 2 - Como Próprio Usuário:

  • Na página de login, clique "Esqueci minha senha"
  • Um email será enviado com link para reset
  • Clique no link e defina nova senha

Tipo de Usuário: Define o papel dentro da empresa (ADMIN, GERENTE, FUNCIONÁRIO, etc)

Staff Status (is_staff): Define se pode ou não acessar o painel de admin (/admin/)

Resumo:

  • Tipo: O quê faz? (Gerencia vendas, estoque, etc)
  • Staff: Acesso ao painel técnico Django? (SIM/NÃO)

O sistema é 100% isolado por empresa:

  • Cada usuário tem um campo "empresa" que o identifica
  • Toda query SQL filtra automaticamente por empresa
  • Um usuário de Empresa 1 NUNCA consegue acessar dados de Empresa 2
  • Mesmo que tente "hackear", o sistema bloqueia

Exemplo de proteção: Se um usuário de Empresa 1 tenta acessar a URL de um produto de Empresa 2, recebe erro "Acesso Negado"

📋 Etapa 1: Solicitação de Compra

O que fazer aqui:

  • Preencha os dados gerais da solicitação
  • Adicione todos os itens que deseja comprar (Produto, Quantidade, Unidade)
  • Revise a quantidade total antes de salvar

Próximo passo: Após salvar, você irá criar uma cotação para que os fornecedores enviem propostas de preço.

{% elif etapa == 'cotacao' %}
📊 Etapa 2: Cotação de Preços

O que fazer aqui:

  • Adicione fornecedores que irão enviar propostas
  • Para cada item, preencha as propostas de preço de cada fornecedor
  • Selecione a melhor opção (menor preço ou outro critério)
  • Após selecionar todas as propostas, conclua a cotação

Próximo passo: Após concluir, você irá gerar os pedidos de compra para os fornecedores selecionados.

{% elif etapa == 'pedido' %}
📦 Etapa 3: Pedido de Compra

O que fazer aqui:

  • Revise todos os dados do pedido (fornecedor, itens, preços)
  • Marque como ENVIADO quando o fornecedor receber o pedido
  • Você pode acompanhar o status do pedido (Enviado, Confirmado, Em Entrega, Recebido)

Próximo passo: Quando o fornecedor começar a enviar a mercadoria, você irá criar recebimentos para registrar cada entrega.

{% elif etapa == 'recebimento' %}
✓ Etapa 4: Recebimento e Entrada no Estoque

O que fazer aqui:

  • Criar Recebimento: Registre a chegada dos itens com a Nota Fiscal
  • Adicionar Itens: Especifique quais itens do pedido foram entregues e as quantidades
  • Conferir: Valide se tudo chegou conforme o pedido
  • Dar Entrada no Estoque: Confirme a entrada e atualize o estoque

Estados do Recebimento:

🟡 PENDENTE: Recém criado, aguardando conferência
🔵 CONFERIDO: Conferido, pronto para entrada
✅ FINALIZADO: Entrada processada, estoque atualizado

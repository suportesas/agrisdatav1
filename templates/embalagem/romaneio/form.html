Ajuda — Romaneio de Venda
O que é um Romaneio de Venda?
É a seleção dos pallets do estoque que serão enviados para um cliente específico. Funciona como uma lista de carregamento: você escolhe os pallets, confirma, e o sistema reserva automaticamente cada pallet e libera a impressão das etiquetas com os dados do cliente.
O que acontece depois de salvar?
  1. O romaneio é criado com status Rascunho.
  2. No detalhe, você seleciona os pallets disponíveis usando a busca (por código, tipo ou armazém).
  3. Clique em Confirmar — os pallets ficam com status Reservado e não aparecem mais para outros romaneios.
  4. Imprima as Etiquetas PDF — agora com nome do cliente, cidade, país e dados do booking (se exportação).
  5. Opcionalmente clique em Gerar Pré-venda para criar um Pedido de Venda automaticamente.
  6. Na doca, use o celular na tela de Conferência para escanear cada pallet carregado.
Tipo: Exportação × Mercado Interno
Exportação
Use quando o destino for para fora do país. Exige preenchimento do Booking (reserva de navio) e opcionalmente o Container. As etiquetas incluirão armador, navio, viagem e porto de destino.
Mercado Interno
Use para vendas dentro do país. Os campos de Booking e Container ficam ocultos. As etiquetas incluirão apenas os dados do cliente nacional.
Campos do formulário
Tipo *
Exportação ou Mercado Interno. Define quais campos adicionais aparecem e o formato das etiquetas.
Data *
Data do romaneio, geralmente a data de carregamento ou de emissão do documento.
Cliente *
Destinatário dos pallets. Aparecerá nas etiquetas e no Pedido de Venda gerado.
Booking
Reserva de espaço no navio (somente Exportação). Vincula o romaneio ao armador, navio e porto de destino. Se não houver Booking cadastrado, acesse Exportação → Bookings.
Container
Container específico dentro do Booking (somente Exportação). O número do container aparece nas etiquetas.
Observações
Informações adicionais: temperatura de transporte, instruções especiais, referência do cliente, etc.
Atenção: os pallets só são adicionados após salvar este formulário, na tela de detalhe do romaneio. Aqui você define apenas os dados gerais (cliente, tipo, booking).

Ajuda - Vínculos Motorista x Placa
O que são Vínculos?

Os vínculos registram qual motorista estava operando qual veículo (ou conjunto de veículos) em determinado período. Este controle é essencial para rastreabilidade e responsabilização, especialmente em casos de multas de trânsito.

Como Criar um Vínculo
  1. Clique no botão Novo Vínculo
  2. Selecione o motorista
  3. Selecione a placa principal (veículo que será operado)
  4. Se houver, selecione os reboques que compõem o conjunto
  5. Informe a data de início do vínculo
  6. Deixe a data fim vazia se o vínculo ainda estiver ativo, ou preencha quando encerrar
  7. Adicione observações se necessário
⚠️ Importante: O sistema não permite vínculos sobrepostos. Se tentar vincular um motorista ou placa que já está vinculado no mesmo período, você receberá um erro.
Consultar Vínculos Históricos

Use o botão Consulta Histórico para:

  • Identificar responsável por multa: Informe a placa e a data da infração para descobrir qual motorista estava com o veículo
  • Ver histórico de operações: Informe o motorista e o período para ver todos os veículos que ele operou
Status dos Vínculos
  • ATIVO - Vínculo habilitado no sistema e com checkbox "Ativo" marcado
  • INATIVO - Vínculo desabilitado (checkbox "Ativo" desmarcado)

💡 Dica: Use o campo "Ativo" para desativar temporariamente vínculos sem deletá-los. Vínculos inativos não aparecem nas consultas históricas, mas permanecem no banco de dados para auditoria.

Editar/Desativar Vínculo

Para desativar um vínculo, clique no ícone e desmarque o checkbox "Vínculo Ativo". Você também pode preencher a Data Fim para registrar quando o motorista parou de operar o veículo.

Conjuntos de Veículos

Você pode vincular não apenas a placa principal, mas também os reboques. Isso é importante para operações com carretas compostas (cavalo mecânico + reboque), pois o sistema registrará todo o conjunto.

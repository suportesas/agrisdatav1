O que é um Grupo Corporativo?

Um Grupo Corporativo é um container administrativo que permite agrupar múltiplas empresas sob uma mesma holding ou corporação.

Exemplos de uso:
  • Holding Agrícola: Várias fazendas em diferentes estados (SC, PR, SP)
  • Grupo de Exportadores: Múltiplos packings em diferentes regiões
  • Franquia: Várias filiais da mesma empresa em cidades diferentes
  • Conglomerado: Empresas relacionadas que precisam de consolidação

Benefícios:

  • ✅ Visualizar dados consolidados de todas as empresas
  • ✅ Gerar relatórios agrupados
  • ✅ Gerenciamento centralizado
  • ✅ Controle de acesso por grupo
  • ✅ Facilitar auditoria e compliance

Quando Usar Grupos Corporativos?

Use Grupos Corporativos quando você tem:

Múltiplas Empresas Mais de uma empresa relacionada
Mesma Holding Empresas sob o mesmo grupo corporativo
Necessidade de Consolidar Precisa de relatórios agrupados
Gerenciamento Centralizado Um admin gerencia várias empresas
Nota: Grupos Corporativos são opcionais. Você pode continuar usando apenas empresas individuais se preferir.

Passo 1: Criar um Novo Grupo Corporativo

  1. Acesse o Menu:
    Menu Principal → GESTÃO DO SISTEMA → Grupos Corporativos → Novo Grupo
  2. Preencha os Dados:
    Campo Descrição
    Nome * Ex: "Carrefour Brasil S.A." - Nome da holding/grupo
    CNPJ Ex: "12.345.678/0001-99" - Opcional, para referência
    Descrição Uma breve descrição do grupo (opcional)
    Email Email para contato da holding
    Telefone Telefone de contato
    Logo Imagem da logomarca (PNG/JPG até 2MB)
    Status * ATIVO, INATIVO ou SUSPENSO
    Administrador Usuário responsável pelo grupo
  3. Clique em "Salvar"
    Seu grupo corporativo foi criado com sucesso!
Dica: Você pode editar essas informações depois clicando em "Editar" na página de detalhes.

Passo 2: Vincular Empresas ao Grupo

  1. Acesse o Grupo:
    Menu principal → Grupos Corporativos → Listar → Clique no nome do grupo
  2. Clique em "Adicionar Empresas"
    Adicionar Empresas
  3. Selecione as Empresas:

    Uma lista aparecerá mostrando todas as empresas não vinculadas a nenhum grupo.

    Dica: Use Ctrl + Click (ou Cmd + Click no Mac) para selecionar múltiplas empresas de uma vez.

  4. Clique em "Adicionar Selecionadas"
    As empresas foram vinculadas ao grupo!
⚠️ Atenção:
  • Uma empresa só pode estar vinculada a UM grupo
  • Ao vincular, a empresa deixa de ser "solta" e passa a fazer parte do grupo
  • Você pode remover uma empresa do grupo depois se precisar

Passo 3: Visualizar Consolidados e Relatórios

  1. Na página de Detalhes do Grupo:

    Você verá automaticamente:

    • Logo/Informações - Dados do grupo
    • Consolidado - Número de empresas, usuários, fazendas, produtos
    • Empresas Vinculadas - Tabela com cada empresa
  2. Clique em "Relatório" para ver um resumo consolidado

    O relatório mostra dados agregados de todas as empresas do grupo, facilitando a visualização de KPIs consolidados.

  3. Remover Empresa (se necessário):

    Na tabela de empresas, clique no ícone X para remover uma empresa do grupo.

    Nota: Remover do grupo não deleta a empresa, apenas desvincula-a.
Dados Consolidados Disponíveis:
Empresas Quantidade de empresas no grupo
Usuários Soma de limite de usuários de todas as empresas
Fazendas Soma de limite de fazendas
Produtos Soma de limite de produtos

Permissões e Acesso

Quem pode fazer o quê:

Permissões:

  • ✅ Criar novos grupos
  • ✅ Editar QUALQUERgrupo
  • ✅ Deletar grupos (sem empresas)
  • ✅ Ver todos os grupos
  • ✅ Adicionar/remover empresas
  • ✅ Ver consolidados de qualquer grupo

Permissões:

  • ✅ Editar SEU grupo
  • ✅ Adicionar empresas ao SEU grupo
  • ✅ Remover empresas do SEU grupo
  • ✅ Ver relatório do SEU grupo
  • ❌ Ver dados de outros grupos
  • ❌ Criar novos grupos
Exemplo: João Silva é admin de "Carrefour Brasil" e só pode gerenciar esse grupo.

Permissões:

  • ❌ Acessar Grupos Corporativos
  • ✅ Usar a empresa normalmente
  • ✅ Ver dados da empresa (não do grupo)
Nota: Usuários normais trabalham nas empresas individuais. Grupos são gerenciados apenas por Admins.

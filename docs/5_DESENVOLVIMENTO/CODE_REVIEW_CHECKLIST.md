# Checklist de Code Review

Owner: Engenharia
Status: Draft
Last Updated: 2026-07-01
Scope: Qualidade de entrega

## Regras de revisao
- Regra de negocio alterada esta documentada?
- Calculo alterado possui formula e teste?
- Condicional critica possui tabela de decisao atualizada?
- Existe risco de quebra multiempresa?
- Endpoint novo/alterado foi documentado?

## Itens tecnicos
- Validacoes de entrada estao completas?
- Uso correto de Decimal em dinheiro/fiscal?
- Mudancas de status respeitam fluxo permitido?
- Logs/auditoria estao adequados ao impacto?
- Testes cobrem cenario feliz, borda e regressao?
